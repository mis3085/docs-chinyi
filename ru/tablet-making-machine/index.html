Полный обзор решений для фармацевтического оборудования
#

Chin Yi признана ведущим производителем в секторе фармацевтического оборудования, предлагая разнообразный портфель техники, разработанной для удовлетворения потребностей современного фармацевтического производства. Наши решения ориентированы на производительность, долговечность и адаптацию к специфическим требованиям клиентов.

Машины для капсул
#

Доступен полный ассортимент оборудования для капсул, включая машины для наполнения, инспекции, полировки, сортировки и укладки. Эти машины разработаны для эффективного и точного производства капсул и контроля качества.
